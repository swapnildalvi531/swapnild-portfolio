SWAPNIL DALVI — VIDEO EDITOR PORTFOLIO — QUICK SETUP

Files:
- index.html: website content and project cards
- style.css: visual design, responsive layout and animations
- script.js: project viewer, Instagram embeds, filters and interactions

HOW TO ADD YOUR REAL REELS
1. Open script.js in a text editor.
2. Find the four project cards in index.html; each has data-reel="ADD_..._REEL_URL".
3. Your VERTEX, Brezza and Audi reel URLs are already added to index.html. Travel/storytelling is left as coming soon until you provide a reel link.
4. Save and open index.html in Chrome. Click a project card to open its reel viewer.
5. Instagram embeds may require internet access and can be affected by Instagram privacy, embed availability, browser restrictions or account settings. If an embed fails, the button to open the original Instagram post is still available.

HOW TO SET YOUR NAME
- Your display name, Swapnil Dalvi, is already set in index.html.
- Edit the title and meta description in the <head> to match your brand.

HOW TO SET WHATSAPP
- In index.html, find the WhatsApp link with 91XXXXXXXXXX.
- Replace it with your full number including country code, digits only, no +, spaces or dashes. Example format: https://wa.me/91XXXXXXXXXX?text=...
- Do not publish a number unless you want clients to contact it.

HOW TO ADD A LOCAL VIDEO INSTEAD
- Put an MP4 file in the assets folder.
- In the matching card in index.html, set data-video="assets/your-video.mp4".
- This plays the video inside the modal. Only publish videos you own or have permission to use.

FREE PUBLISHING OPTION
You can publish this static site using GitHub Pages (free) or another static host. Before publishing, replace placeholders, test mobile view, and verify all links. Google Fonts and Instagram embeds need internet access.
